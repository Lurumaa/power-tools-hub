# Editor mockup

## Запуск
1. Положи свои видео в папку `videos/` под именами `clip1.mp4` и `clip2.mp4`
   (сейчас там тестовые заглушки — просто замени их).
   Другие имена — поправь массив `MEDIA_FILES` в начале `<script>` в index.html.
2. Открой `index.html` двойным кликом в Chrome.
   Если браузер ругается на файлы — запусти из папки: `python3 -m http.server 8000`
   и открой http://localhost:8000
3. Можно также просто перетащить любое видео на страницу или нажать Import.

## Хоткеи
Space — play/pause · C — razor · V — select · Ctrl/⌘+K — split · Del — удалить
← → — кадр (Shift — секунда) · + / − — зум · \ — fit · Ctrl+колесо — зум
