# Editor mockup

## Запуск
1. Поклади свої відео в папку `videos/` під іменами `clip1.mp4` і `clip2.mp4`
   (зараз там тестові заглушки — просто заміни їх).
   Інші імена — виправ масив `MEDIA_FILES` на початку `<script>` в index.html.
2. Відкрий `index.html` подвійним кліком у Chrome.
   Якщо браузер свариться на файли — запусти з папки: `python3 -m http.server 8000`
   і відкрий http://localhost:8000
3. Можна також просто перетягнути будь-яке відео на сторінку або натиснути Import.

## Гарячі клавіші
Space — play/pause · C — razor · V — select · Ctrl/⌘+K — split · Del — видалити
← → — кадр (Shift — секунда) · + / − — зум · \ — fit · Ctrl+коліщатко — зум
